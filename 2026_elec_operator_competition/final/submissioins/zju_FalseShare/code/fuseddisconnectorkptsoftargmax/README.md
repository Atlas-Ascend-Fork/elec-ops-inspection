## 算子实现介绍

基于 Ascend C 实现隔离开关关键点坐标与置信度融合解码。输入输出均为 FP32，完成 3×3 卷积（padding=1，含 bias）、温度缩放、全空间数值稳定 Softmax、坐标期望及半像素坐标还原；scores 为卷积热图的空间最大值。

按批次和空间尺寸选择 Cube/Vector 融合路径，采用 FP32 纵向投影与水平合并、分块并行、片上缓存复用和流水预取，减少中间结果搬运与同步。部分 Cube 路径使用 FP16 高低位分解承载中间投影，并以 FP32 合并；零权重路径在设备端检查后直接计算均匀分布结果。Host 仅负责形状、属性及 tiling，张量计算均在设备端执行。开源代码以本队赛事最佳通过提交为基线。
