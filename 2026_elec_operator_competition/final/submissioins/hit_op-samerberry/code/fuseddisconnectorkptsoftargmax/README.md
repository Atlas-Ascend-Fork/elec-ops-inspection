## 算子实现介绍

## 算子: fuseddisconnectorkptsoftargmax

本算子面向昇腾 910B（Ascend C）向量众核微架构实现 `FusedDisconnectorKeypointSoftArgmax`（FP32）五阶段全链路融合解码，采用 `src_modular/` 模块化单源组织并经确定性脚本内联组装为标准交付工程。核心技术创新与泛化设计如下：

1. **全链路零热图物化融合与纯向量核底座**：将零填充 $3\times 3$ 卷积、原始热图峰值提取、$\tau$ 缩放全图数值稳定 Softmax、二维 Soft-Argmax 期望与半像素中心坐标还原融合于单一纯向量核（`ASCENDC_TPL_MIX_AIV_1_0` + `SetScheduleMode(1)`），规避混合核包装器的隐式清零开销；结合 `ICachePreLoad` 指令预取与冷分支 `noinline` 栈帧隔离消除热循环寄存器溢出，实现整张热图、概率图与二维坐标网格的**零全局内存（GM）物化**。
2. **零 Im2Col 预移位三视图搬运与零 Bank 冲突三累加器**：利用 MTE2 `DataCopyPad` 硬件左右填零，以 4 通道批处理方式直接构建左/中/右预移位对齐视图，配合首尾单 bit 向量掩码（`0x1` / `0x80`）单指令批量消隐跨行边界串扰，彻底消除 `Im2Col` 显存膨胀与非对齐读取；设计 384-float 模冲突规避步长代数与随宽度 $W$ 动态相移（`(0, W&gt;&gt;3, 2W&gt;&gt;3) + 8` 个 Bank Group）的三路行相位独立累加器，配合 8 轮 Ping-Pong 双缓冲流水，在任意 8 对齐宽度下实现 `vaxpy` 读写零 Bank 冲突与搬算重叠。
3. **二维边缘投影降维与在线重缩放统计包协议**：卷积后原址复用双缓冲 UB 空间，将二维坐标期望正交分解为一维行投影（`WholeReduceSum`）与列投影（乘以片上倍增生成的 1D 坐标向量），使坐标加权复杂度由 $O(KHW)$ 降至 $O(K(H+W))$；设计 96B（24-float）跨核充分统计包与 `SyncAll&lt;true&gt;()` FFTS 硬件栅栏协议，保留未缩放原始峰值无损直出 `scores`，并通过复现生产核 `s * invTau` 独立舍入顺序的在线指数重缩放消除小 $\tau$ 主峰舍入偏差，多批次下由空闲专核并发完成全批次分数二叉树归约。
4. **空间/关键点正交双模分裂与位级精确退化快路**：基于硬件核数预算、最小向量有效载荷（控制 Halo 重叠率）与 UB 容量守卫自适应路由至 **`MODE 1`（2D 空间条带 `K4` 全关键点复用）** 或 **`MODE 2`（3D 空间条带×关键点对 `K2×2` 正交分裂，半幅权重加载 + 哨兵包统一归约 + 单笔 32B 完整块写出防缓存行争用）**；同时复用常驻权重缓冲区构建五级 `Or&lt;uint16_t&gt;` 树折叠与符号位掩码（`0x7fffffff`）的 IEEE-754 位级精确全零滤波器快路，零近似误差直出解析中心坐标。
5. **参数化通用设计与无状态复用鲁棒性**：全链路按硬件与几何不变量参数化实现，原生支持不同芯片变体动态 AIV 核数感知、非整除高度余数均衡切分与上下边界自适应识别、非 2 幂次条带哨兵归约树、$W \le 64 / W &gt; 64$ 自适应分段归约及全温度域 $\tau \in (0, +\infty)$ 双层防溢出稳定计算（模块化代码库同时内置三行滚动缓冲通用流式引擎支撑非受限任意形状演进）；全程仅需数 KiB 动态 Workspace，无静态计数器或预清零假设，在算子缓存与脏内存复用场景下严格保持确定性精确输出。
