## 算子实现介绍

基于 Ascend C 实现 float32 批量方阵行列式，最终版本为 R317。Host 根据矩阵阶数、批数、UB 容量及 AIV/AIC 资源选择计算路径并分配 workspace。

小阶（N≤16）将矩阵驻留 UB，静态 5–16 阶采用两主元前缀与四阶尾项求值，按 batch 分配核。中阶（16&lt;N≤64）采用 UB 内向量消元，静态主路径使用两主元块逆和 Schur 更新，并重叠独立的主元行及系数准备。大阶（N&gt;64）在资源允许时由 AIV 完成面板分解、Cube 完成块更新，按组协作并同步就绪状态，其他情况使用通用路径。R317 对强相消的 2×2 块切换两步消元并读取真实第二主元，修复大阶符号回归。

通过编译期特化、对齐布局、减少 tiling 读取及精简同步降低开销，触发恢复条件时在同次 NPU 调用内使用带部分主元的通用内核重算。最终官方提交 1177870 为 12/12 Pass、99.38 分。已知快速路径在病态输入及 FP32 中间溢出情形下仍有精度边界。
