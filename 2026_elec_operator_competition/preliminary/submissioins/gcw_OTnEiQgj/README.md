## 算子: lstsq

基于 Ascend C 实现面向 Ascend 910B 的 LinalgLstsq 批量列满秩最小二乘求解算子（支持 FP32/BF16 输入输出与残差平方和计算）。Host 侧根据批次大小 B、矩阵维度 (M, N)、右端项列数 K、UB 32 字节对齐块步长及可用 AIV 核数规划 Workspace 并分派执行路径。

小规模方阵（N≤64）将增广矩阵按 32 字节对齐常驻片上 UB，按 batch 分核并行，采用基于可用行位掩码的原位部分主元 Gauss-Jordan 消元、尾块 8 行合并更新与 Gather 重排输出；中大规模方阵（64<N≤256）采用单核或多核协同波前面板 LU 分解，结合上下三角回代与一步全精度残差迭代精化提升数值精度；超定矩阵（M>N）采用向量化 Householder QR 分解、正交变换及上三角回代完成最小二乘解与各列残差平方和计算。

## 算子: treelinemindistance

基于 Ascend C 实现面向 Ascend 910B 的三维树障点到导线线段最小欧氏距离及最近线段索引计算算子（支持 FP32/FP16 输入输出，最近索引为 INT32 并按最小索引优先处理平局）。Host 侧根据批次大小 B、点集规模 M、线段数量 N、UB 容量及可用 AIV 核数制定通用分块策略，并预计算 32 位向上取整倒数乘法器以消除设备侧 64 位整数软除法。

Kernel 侧按数据规模划分为极小规模单核、单线段点分块、单点线段归约、短线段块广播（Brcb）、中大规模点线分块（32/64 点块）以及超大规模两阶段混合精度筛选路径。FP16 输入在片上提升为 FP32 计算点到线段投影、截断与距离平方，结合 WholeReduceMin 层次化归约及单元素尾块标量快径求取最小距离与对应线段索引，最后开方并按输入类型写回全局内存。
