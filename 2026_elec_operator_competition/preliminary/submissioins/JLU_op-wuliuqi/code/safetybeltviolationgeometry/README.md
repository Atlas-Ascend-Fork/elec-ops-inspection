## 算子实现介绍

SafetyBeltViolationGeometry 是基于 Ascend C 实现的安全带低挂高用几何判定融合算子，面向 Ascend 910B，支持 FP16、FP32 坐标输入。算子根据人员框计算判定参考线，再结合可选阈值与安全带挂点纵坐标进行严格大于比较，输出逐样本的 0/1 违规标志，相等边界判为不违规。

实现由 Host Tiling 和 Device Kernel 两部分组成。Host 根据数据类型、Batch、真实属性及平台资源选择执行计划，按 FP32、FP16 各六个尺寸段组织十二个分支，在通用区间内部保留常用尺寸的编译期计划。启动核数与工作核数分别配置，各分支通过 Init、`CopyIn`、`Compute`、`CopyOut` 组织执行流程。

Kernel 将输入搬入 UB 后，在片上完成抽列、参考线计算、比较和结果生成，中间值不写回 GM。FP16 路径先提取 y1、y2、cy 三列，再仅对有效列提升精度，将转换元素数从约 6N 减少到 3N；几何运算和比较使用 FP32，并保留分步舍入顺序。FP32 路径使用掩码及 VCPADD 等指令提取有效列。

部分分支为两路输入设置独立的就绪事件，使人员框先到达时能够提前计算参考线，在比较需要 cy 时再等待挂点。实现同时采用常量搬运参数、真实属性守卫下的比例模板、掩码及常量块复用，减少参数准备和重复操作，并保留必要的流水线依赖同步。
