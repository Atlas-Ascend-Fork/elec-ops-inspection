## 算子实现介绍

本实现基于 Ascend C 面向 910B 编写。Host tiling 根据批次、点数、线段数和 AIV 核数，在点主序与线段矩阵两条执行路径间选择，并按有效工作量划分多核。片上 UB 复用树障点坐标、线段几何、广播数据和归约中间量；线段矩阵路径采用 64×64 分块，向量化完成投影、Clamp、距离平方及 ReduceMin，点较多而线段较少时走点主序路径。FP16 输入统一转换为 FP32 计算，最终距离转回原类型，最近索引全程使用 INT32，并按最小索引优先处理平局。实现支持非 32 元素对齐的尾块、零长度线段和双缓冲搬运流水。源码已通过官方 17/17 测试点，并在 910B 真机上完成精确索引验证。
