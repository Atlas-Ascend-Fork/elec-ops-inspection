## 算子实现介绍

采用按矩阵阶数、Batch 数量、数据对齐及 UB 容量自适应分流的多路径实现。小中型矩阵整体驻留 UB，使用带部分主元选取的 LU 分解，在 UB 内完成主元搜索、行交换、消元及行列式累乘，并利用向量指令加速尾部行更新，减少 GM 读写。批量矩阵由多个 AI Core 按矩阵独立并行处理；大型矩阵采用分组多核协作完成主元搜索和分块更新。对经过完整结构检查的三角矩阵直接计算对角线乘积，未命中时回退通用 LU 路径，同时正确处理换行符号及奇异矩阵。Workspace 和行跨度按 32B 对齐，以提高数据搬运效率。
