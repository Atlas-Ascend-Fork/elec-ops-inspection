## 算子实现介绍

基于 Ascend C 实现实对称矩阵特征值与特征向量分解算子 LinalgEigh，全部核心计算在昇腾 910B 的 AI Core Vector 单元与片上 UB 内完成，Host 侧仅负责分块参数计算与执行模式派发。Host 侧将矩阵行跨度按 32 字节即 8 个 float 对齐，并根据矩阵维度 N 与批量大小 B 划分为单核批处理与多核协作两类模式：当 N 不超过 64 时采用单核批处理模式，将输入矩阵按每核分配的 batch 分块常驻片上 UB；当 N 大于 64 时采用多核协作模式，每个核组由多个 AIV 核通过全局内存软同步屏障协同求解单个矩阵。Kernel 侧计算流程分为三对角化、特征值求解、特征向量求解与逆变换四个阶段：首先对输入矩阵做最大绝对值缩放以防止浮点溢出，并提取下三角或上三角部分完成对称化；随后通过向量化 Householder 反射将实对称矩阵约化为对称三对角矩阵，在中等规模与大规模尾块阶段采用双步融合归约策略隐藏向量归约延迟，在 N 大于 64 的前段消元中由多核按行条带并行计算矩阵向量乘与秩二更新；对中等规模矩阵采用带移位 QR 迭代同步累积正交变换矩阵，对大规模矩阵采用分治法结合单核快速路径与多核并行牛顿法求解长期方程及秩一修正；最后按升序重排特征值与特征向量，并将每个特征向量中绝对值最大分量的符号统一调整为正号后写回全局内存。
