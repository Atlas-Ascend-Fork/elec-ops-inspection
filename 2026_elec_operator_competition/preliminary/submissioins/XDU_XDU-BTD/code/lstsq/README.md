## 算子实现介绍

1. 按矩阵规模设计不同的求解结构。 针对小矩阵，采用带安全检查的增广消元与逆算子快路，将初解和后续修正转化为适合 Vector 执行的矩阵向量运算，减少连续三角回代的串行依赖；针对较大矩阵，采用共享 QR 分解和分块求解，提高因子复用率与并行度。
2. 融合分解与求解，减少中间步骤。 例如在50阶专用路径中，将右端项嵌入增广矩阵的原有填充列，随消元过程直接生成初解；在64阶路径中，让消费者直接读取增广逆表示，省去中间逆矩阵的重新打包与复制。
3. 构建 Cube 与 Vector 协同的大矩阵计算路径。 将适合矩阵乘法的工作交给 Cube，将残差、数值检查和修正交给 Vector；多个右端项共享因子，原矩阵分块在核内驻留并跨修正轮复用。同时依据实际误差信息选择不同阶数的多项式修正路径，减少满足条件时的计算量。
4. 以高精度残差补偿支撑快速求解。 在 FP32 路径中保留高低位拆分乘积、TwoSum 补偿归约和基于原始方程的迭代修正，降低舍入与抵消误差。结合主元、有限性和逆范围等检查，在快路不满足条件时进入带主元或 LU 回退路径，兼顾速度与数值可靠性。
5. 围绕最终消费者重构数据布局与流水。 由生产阶段直接生成后续计算需要的布局，删除重复清零、索引生成、格式转换和无效写入；根据缓冲区最后读者安排空间复用与同步，并提前发起输入 DMA，使数据搬运与独立准备工作重叠，减少关键路径上的等待。
